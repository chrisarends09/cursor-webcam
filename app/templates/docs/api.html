API Documentation

Welcome to the Webcam Manager API documentation. The API provides programmatic access to webcam management functionality.

Authentication

The API uses Bearer token authentication. To get a token:

  1. Log in to your account
  2. Make a POST request to /api/auth/token
  3. Include the token in subsequent requests using the Authorization header: Authorization: Bearer your_token_here

Rate Limiting

API endpoints are rate limited to prevent abuse. Current limits:

  • General endpoints: 100 requests per minute
  • System status: 60 requests per minute
  • Snapshot statistics: 30 requests per minute
