The run.sh script run the webcam_snapshot.py script
# Make it executable with chmod +x run.sh

The webcam_snapshot.py script takes a snapshot of the webcam and saves it to a file
You get a choice of how often you want to take a snapshot
The snapshots are saved in the snapshots directory
The snapshots are sent to Discord automatically

# The run.sh script is a simple script that runs the webcam_snapshot.py script
It is a wrapper around the webcam_snapshot.py script
